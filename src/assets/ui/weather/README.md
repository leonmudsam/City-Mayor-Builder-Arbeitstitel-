# Wetterbilder

Optionale Wetter- und Tageszeitillustrationen. Fehlt ein Bild, bleiben die
Bedienelemente und die prozedurale 3D-Atmosphäre vollständig nutzbar.

- `weather_cycle_premium.jpg` — KI-generiertes 3:1-Panorama derselben
  Alpeninsel bei Sonne, Sommerregen und Morgennebel. Das Wetterfenster nutzt
  die drei Drittel als zusammengehörige Preset-Motive.

Laufzeit-Vertrag: Die Auswahl ändert ausschließlich die Renderer-Atmosphäre
(`environmentSettings.ts`/`SkyEnvironment.ts`), nie Wirtschaft, Bedarfe,
Belohnungen oder den Save.
