# Tutorial-Drop-ins

Vorbereitet für maus- und tastaturbezogene Illustrationen. Redesign 4.0 erklärt
die Bedienung zunächst kompakt im Screen: Straßenklick/-ziehen, freie Fläche zum
Verschieben, Mausrad/+/−, Rechtsklick, Leertaste, F, R und Esc.

Zukünftige Bilder: transparente PNG/WebP, keine fest eingebrannte Sprache;
Tastenbeschriftungen bleiben HTML für Lokalisierung und Barrierefreiheit.
