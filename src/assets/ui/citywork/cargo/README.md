# Ladungsbilder

512×512 PNG mit Transparenz: `cargo_food`, `cargo_wood`, `cargo_stone`,
`cargo_water`, `cargo_materials`. Die UI ordnet `freshwater` bewusst
`cargo_water` zu; gemischtes Baumaterial nutzt `cargo_materials` als Bild, ohne
einen neuen Simulations-Resource-Typ zu erfinden.

Generierungsmodus: `stylized-concept`. Promptbasis: „Single premium stylized 3D
cartoon city-builder cargo bundle for [resource], compact readable silhouette,
warm painted materials, subtle navy/gold presentation accents, no text, no
letters, isolated on flat #ff00ff chroma background.“ Danach Soft-Matte/Despill
und Größenreduktion auf 512×512.
