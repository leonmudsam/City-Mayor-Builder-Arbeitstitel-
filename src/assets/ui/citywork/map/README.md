# Karten-Drop-ins

Vorbereiteter Ordner für spätere topografische Muster, Bezirksstempel und
Kartenlegenden. Das Redesign 4.0 zeichnet Gelände, Wasser, Straßen, Gebäude,
Schatten, Verkehr und Route performant in einem Canvas. Ein Bild darf diese
kanonischen Daten nicht ersetzen.

Namensvorschlag: `map_texture_<funktion>.webp`, nahtlos und ohne Beschriftung.
