# Fahrzeug-UI-Drop-ins

Vorbereiteter Ordner für Stadtarbeit-spezifische Fahrzeugkarten. Derzeit nutzt
die Auswahl die zentrale Fahrzeug-Registry unter `src/assets/vehicles/`, damit
Planung und 3D-Welt dieselbe Bildidentität behalten. Neue Bilder nur nach
`<imageKey>.png` benennen und weiterhin über die Registry laden.
