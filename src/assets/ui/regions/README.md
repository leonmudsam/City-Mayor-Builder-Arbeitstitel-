# Regionsbilder

Hero- und Vorschaubilder für Regionen. Fehlende Dateien nutzen den prozeduralen
oder allgemeinen Regions-Fallback.

- `region_unlock_highland.jpg`: KI-generierter Hero für Gebirge und Hügelland.
- `region_unlock_fertile.jpg`: KI-generierter Hero für Ebene, Flusstal und
  fruchtbares Land.
- `region_unlock_coast.jpg`: KI-generierter Hero für Küste, See und Insel.
